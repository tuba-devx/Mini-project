#  Amazon Clone - Mini Project
A simple **Amazon-inspired e-commerce homepage clone** created as a mini project using **HTML and CSS**.
This project was developed to practice webpage structure, navigation bars, layouts, styling, and responsive-looking UI design.
##  Features
-  Amazon-inspired homepage design
-  Navigation/header section
-  Search bar with category selection
-  Delivery location section
-  Account & Lists section
-  Returns & Orders section
-  Shopping cart section
-  Navigation menu
-  Promotional hero banner
-  Product/category cards
-  Clean and modern layout

##  Technologies Used

- **HTML5**
- **CSS3**
- **Font Awesome** for icons
